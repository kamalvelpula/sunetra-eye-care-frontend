# Sunetra Eye Care – Frontend

A modern, responsive eye care website built using React and Vite. Sunetra Eye Care helps visitors explore eye care services, view doctors, book appointments, and contact the clinic.

## ✨ Features

- Responsive and modern user interface
- Home page with clinic information
- About Us section
- Eye care services
- Doctors section
- Gallery and testimonials
- Online appointment booking
- Contact form
- WhatsApp contact integration
- Secure admin login interface
- Admin dashboard for managing appointments, messages, and services

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/kamalvelpula/sunetra-eye-care-frontend.git
```

### 2. Navigate to the Project

```bash
cd sunetra-eye-care-frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
